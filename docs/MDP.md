# MDP — Model Development Protocol

> **Replace this file with your existing MDP content.**
>
> All agents (Architect, CTO, Orchestrator, Coder) are instructed to read and follow this document. If it is empty or stub content, they will operate without it — keep it filled and current.

## Expected contents

At minimum this document should answer:

- What stages a model/feature goes through from idea → production
- What artifacts each stage must produce
- What gates are required to move between stages
- How decisions are documented
- How rollbacks are handled

## Used by

- `agents/architect.md` — when drafting `PLAN.md` phases
- `agents/orchestrator.md` — when sequencing tasks
- `agents/coder.md` — when deciding what counts as "done"
- `agents/cto.md` — when reviewing plans and merges
